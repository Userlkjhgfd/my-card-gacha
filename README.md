# My Idol Gacha — 改良版

## 内容
- ライブ風ガチャ演出（照明・ペンライト・レアリティ演出・演出スキップ）
- 育成画面（経験値バー、スタミナ回復カウントダウン、次レベル能力値予測）
- カード図鑑（名前検索、レアリティ絞り込み、お気に入り、未入手表示）
- 複数チーム、チーム名、リーダー設定
- JSON形式のバックアップと復元
- データ形式バージョン管理と旧保存データの簡易検出・移行
- スタミナ上限100、5分ごとに1回復、満タン時は回復停止
- レッスン：ボーカル20/20EXP、ダンス30/30EXP、特別50/50EXP（1日3回）
- レアリティ別最大Lv：N20 / R30 / SR40 / SSR50
- 能力値は内部でLvごとに+0.5、画面表示は小数点以下を切り捨て

## GitHub Pagesへの反映
1. 現在のアプリを開き、「カード管理」→「セーブデータ保護」→「バックアップを書き出す」を実行。
2. 可能なら現在のGitHubリポジトリのファイルもPC等へ保存しておく。
3. このZIPを解凍し、`index.html`、`style.css`、`app.js`、`manifest.json` を既存リポジトリのルートへアップロードして置き換える。
4. Commit changesを押して、Pagesが更新されるまで待つ。
5. 同じ端末・同じブラウザ・同じURLで開き、カードと所持データを確認する。
6. 旧データが自動移行されなかった場合は、旧アプリで書き出したバックアップを新アプリで読み込む。

## データ保護の重要事項
- このアプリはブラウザのlocalStorageへ保存します。端末変更、ブラウザデータ削除、別ブラウザへの移行ではデータが自動同期されません。
- 新しいアプリは保存キー `myIdolGachaSave` を使い、いくつかの一般的な旧キーを検出して移行を試みます。ただし元のアプリの正確な保存形式を確認できていないため、すべてのデータを自動移行できる保証はありません。
- 必ず更新前にバックアップしてください。復元は現在の保存データを置き換えます。
- 画像はブラウザ保存容量を使います。登録画像は2.5MB以下を推奨。
- ガチャ確率は app.js 内の `rarityRoll()` で設定しています。現在はSSR 3%、SR 12%、R 35%、N 50%です。
- チーム人数の上限は固定していません。
