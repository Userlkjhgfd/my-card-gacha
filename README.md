# My Card Gacha（iPhone向けPWA）

自分専用のカード収集・育成ガチャアプリの初期版です。HTML/CSS/JavaScriptだけで動作し、GitHub Pagesで公開できます。

## 主な機能
- 1時間ごとにガチャ権利を1回分追加。未使用分は蓄積（上限なし）
- 単発・10連ガチャ
- 自分で画像・名前・レアリティ・初期looks/styleを登録
- レアリティ N / R / SR / SSR
- 図鑑、検索、レアリティ絞り込み、能力値・レベル・覚醒などで並び替え
- チーム人数を1〜30人で変更、所持カードを選抜
- Lv.1〜99。レベルアップボタンは仮実装で、押すと1レベル上昇
- 同レアリティの重複カード1枚で覚醒。最大5回。能力値は直接上がらず、カードに光る演出
- JSONバックアップの書き出し・読み込み

## GitHub Pagesで公開する
1. GitHubで新しいリポジトリを作成（例：`my-card-gacha`）。
2. このフォルダ内の `index.html`、`style.css`、`app.js`、`manifest.json`、`README.md` をリポジトリ直下にアップロード。
3. GitHubのリポジトリで **Settings → Pages** を開く。
4. Build and deployment の Source を **Deploy from a branch** にし、Branchを `main`、フォルダを `/ (root)` にして保存。
5. 公開されたURLをiPhoneのSafariで開く。
6. Safariの共有ボタン → **ホーム画面に追加** でアプリのように使えます。

## 重要な注意
- 現在のデータはそのiPhoneのブラウザ内（localStorage）に保存されます。別端末への自動同期はありません。ブラウザのデータ消去で消える可能性があるため、カード画像も含めて定期的に「バックアップを書き出す」を使ってください。
- 画像はブラウザ保存容量を考慮して1枚2MB以下に制限しています。
- 権利の時間計算はこの端末の時計に依存するため、端末時刻を変更すると影響を受けます。サーバー同期・改ざん対策はこの初期版にはありません。
- ガチャ排出重みは暫定で N 55 / R 28 / SR 13 / SSR 4。正式な排出率は登録キャラ数によって実際の確率が変わるので、必要に応じて後から調整してください。
- レベルアップ条件・能力値の上昇量は未確定のため、現在は登録時に設定した上昇量を使い、詳細画面のボタンでテスト用にレベルアップできます。
- この版はWebアプリです。App Storeで配布するネイティブアプリではありません。

## 覚醒ルール
- 入手時の覚醒は0。
- 1覚醒につき同レアリティの所持カードを1枚素材として消費。
- 最大覚醒は5。最大まで素材5枚。
- 覚醒でlooks/styleの数値は上昇しません。カード枠と発光エフェクトのみ変化します。
